## App design skills

For app creation or substantial UI work:

- Use `ui-ux-pro-max` for responsive layout, accessibility, design systems, forms, validation and platform conventions.
- Use `frontend-design` for visual hierarchy, brand character and avoiding generic AI-generated interfaces.
- Use `apple-design` only when motion, gestures, sheets, transitions or interaction polish are relevant.

The latest approved product architecture and the existing repository design system override third-party skill suggestions. Do not let these skills invent features, routes, labels or product behaviour.
